# 语音背诵识别功能 — 需求与开发文档

## 一、功能概述

在复习页面新增「语音背诵」模式。孩子对着手机背诵诗词，系统通过语音识别（ASR）将语音转为文字，再与原诗逐字对比，标注正确和错误的位置，给出背诵评分。

## 二、用户故事

1. 进入待复习页面，看到某首诗后，点击「语音背诵」按钮
2. 系统请求麦克风权限（首次使用时），授权后开始录音
3. 屏幕显示实时识别文字，同时隐藏原诗内容
4. 孩子背诵完毕后点击「停止」，或系统检测到长时间静音自动停止
5. 页面展示对比结果：正确的字标绿，错字/漏字标红，多出的字标灰
6. 显示正确率百分比，用户可选择「再背一次」或「完成复习」

## 三、技术方案

### 3.1 语音识别：SFSpeechRecognizer

- 使用 iOS 原生 `Speech` 框架，locale 设为 `zh-CN`
- 通过 `SFSpeechAudioBufferRecognitionRequest` 实现实时流式识别
- 设置 `shouldReportPartialResults = true`，实时显示识别进度
- 利用 `contextualStrings` 传入当前诗词的句子作为提示词，提高识别准确率
- 免费使用，单次最长 1 分钟，对于古诗词背诵（通常 < 30 秒）完全足够

### 3.2 拼音对比（核心算法）

语音识别对古诗词的最大问题是**同音字**——识别出的字可能跟原字不同但发音相同。

**方案：拼音级别对比，容错同音字**

```
原诗:  床前明月光  → pinyin: ["chuáng","qián","míng","yuè","guāng"]
识别:  床前明月亮  → pinyin: ["chuáng","qián","míng","yuè","liàng"]

逐字对比拼音:
  chuáng == chuáng ✅
  qián  == qián   ✅
  míng  == míng   ✅
  yuè   == yuè    ✅
  guāng != liàng  ❌  ← 标记为错字
```

**对比流程：**

1. 预处理：过滤标点符号，只保留汉字
2. 将原诗和识别结果分别转为拼音序列（复用现有 `PinyinHelper`）
3. 去掉声调，只保留声母+韵母（容错声调偏差）
4. 用编辑距离（Levenshtein distance）对齐两条拼音序列
5. 逐位置标记：匹配 / 替换（错字）/ 插入（多字）/ 删除（漏字）
6. 计算正确率 = 匹配字数 / 原诗总字数

### 3.3 声调处理策略

小学生发音可能声调不准，但声母韵母是对的。拼音对比时：

- **默认忽略声调**：`guāng` 和 `guǎng` 视为匹配
- 仅比较声母+韵母部分，去掉数字声调标记

## 五、模块详细设计

### 5.1 SpeechRecognizer（语音识别管理器）

```swift
import Speech

final class SpeechRecognizer: ObservableObject {
    @Published var recognizedText: String = ""
    @Published var isRecording: Bool = false

    private let speechRecognizer = SFSpeechRecognizer(locale: Locale(identifier: "zh-CN"))
    private let audioEngine = AVAudioEngine()
    private var recognitionTask: SFSpeechRecognitionTask?

    /// 请求麦克风和语音识别权限，返回是否全部授权
    func requestAuthorization() async -> Bool

    /// 开始录音识别，contextualStrings 用于提高特定词汇识别率
    func start(contextualStrings: [String])

    /// 停止录音
    func stop()
}
```

**关键实现要点：**

- `start()` 中配置 `AVAudioSession.setCategory(.record, mode: .measurement)`
- 在 `inputNode` 上安装 tap 采集音频 buffer，append 到 `SFSpeechAudioBufferRecognitionRequest`
- `recognitionTask` 回调中更新 `recognizedText`（DispatchQueue.main.async）
- `stop()` 中依次：`audioEngine.stop()` → `removeTap` → `endAudio()` → `cancel task`
- `contextualStrings` 传入当前诗词的所有句子，帮助 ASR 优先匹配诗词用词

### 5.2 RecitationChecker（背诵对比算法）

```swift
struct RecitationChecker {
    /// 单个字的对比结果
    enum CharStatus {
        case correct      // 正确（拼音匹配）
        case wrong        // 错字（拼音不匹配）
        case missing      // 漏字（原诗有但识别没有）
        case extra        // 多字（识别有但原诗没有）
    }

    /// 对比结果
    struct Result {
        let originalChars: [String]       // 原诗汉字列表（过滤标点）
        let statuses: [CharStatus]        // 逐字状态
        let accuracy: Double              // 正确率 0.0 ~ 1.0
        let correctCount: Int
        let wrongCount: Int
        let missingCount: Int
        let extraCount: Int
    }

    /// 对比原诗和识别结果
    static func check(original: String, recognized: String) -> Result
}
```

**`check()` 实现步骤：**

1. 过滤原诗和识别文本中的标点符号
2. 提取汉字序列：`originalChars`、`recognizedChars`
3. 通过 `PinyinHelper` 将每个字转为拼音，再去掉声调（strip tone numbers）
4. 对两条拼音序列计算 Levenshtein 编辑距离，同时记录操作路径
5. 根据操作路径生成 `CharStatus` 数组
6. 统计正确率

**去声调示例：**

```swift
// "chuáng" → 去掉声调数字 → "chuang"
// 使用 CFStringTransform kCFStringTransformStripDiacritics 去掉声调标记
private static func stripTone(_ pinyin: String) -> String
```

入口：在复习页面的诗词内容下方，新增「语音背诵」按钮。

## 七、边界情况处理

| 场景 | 处理方式 |
|------|----------|
| 用户拒绝麦克风权限 | 弹窗提示去系统设置开启，提供跳转链接 |
| 语音识别不可用（老旧机型/无网络） | 按钮置灰，提示「语音识别不可用」 |
| 背诵中途长时间静音（> 5 秒） | 自动停止并进入结果对比 |
| 背诵内容完全为空 | 提示「未检测到语音，请重试」 |
| 背诵内容与原诗完全无关 | 显示 0% 正确率，提示重新背诵 |
| 长诗（如将进酒，> 1 分钟） | 朗读时间在 1 分钟限制内；超长诗后续考虑分段 |

## 八、与现有代码的集成点

| 现有模块 | 集成方式 |
|----------|----------|
| `PinyinHelper` | 复用 `annotate()` 方法获取拼音；新增 `stripTone()` 方法 |
| `ReviewView` | 在诗词内容区添加「语音背诵」按钮，点击后以 sheet 或导航方式进入 `RecitationView` |
| `ReviewEngine.updateRecord()` | 背诵完成后调用，更新学习记录 |
| `Poem.displayLines` | 背诵对比时使用原始 `paragraphs`（不拆行），因为需要逐字对比完整文本 |
