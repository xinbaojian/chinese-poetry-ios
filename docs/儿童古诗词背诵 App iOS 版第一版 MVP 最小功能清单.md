# 儿童古诗词背诵App **iOS版第一版MVP最小功能清单**
定位：只做核心闭环——**诗词浏览背诵 + 艾宾浩斯记忆曲线 + 智能复习提醒 + 自动筛选待复习诗词**，砍掉所有娱乐、社交、复杂统计、小游戏，优先跑通小朋友背诗、自动复习、定时提醒核心流程。

## 一、基础前提（iOS专属）
1. 仅适配 **iPhone iOS**，暂不做iPad适配、不做安卓、不做小程序
2. 本地数据存储，**无需登录注册**，打开即用
3. 支持iOS系统推送通知（复习提醒必备）
4. 全App无广告、无内购、无弹窗冗余功能

## 二、MVP核心资源（最小题库）
1. 内置**部编版小学1-6年级必背古诗词全集**
- 古诗词原始文件在 `/Users/xinbaojian/workspace/front/chinese-poetry` 目录

2. 每首诗词固定字段（最简够用版）
   - 标题、作者、朝代、完整原文
   - 分行排版，大字适合小孩阅读
   - **全文拼音标注**（可手动开关）
   - 简单儿童版释义（精简版，不冗长）
3. 诗词分类（只保留2个够用维度）
   - 按年级：1-6年级分类
   - 全部诗词总库

## 三、核心功能模块（MVP只做5大模块）
### 模块1：首页（核心首页）
1. 展示**今日任务**：今日新学、待复习诗词数量
2. 自动算法筛选：**所有诗词里智能挑出今天该复习的**
3. 入口：「开始今日学习/复习」一键进入
4. 简易数据：已背完多少首、待复习多少首

### 模块2：诗词库
1. 全部诗词列表、按年级筛选
2. 搜索功能：按标题、诗句搜诗词
3. 单首诗词详情页：看原文、开关拼音、看释义
4. 手动加入学习计划：可自选任意诗词开始背诵

### 模块3：背诵+艾宾浩斯记忆曲线（核心引擎）
1. 采用**适配儿童的简化记忆曲线周期**
   新学 → 第1、2、4、7、15天 触发复习
2. 每首诗独立记录：学习时间、复习次数、掌握程度
3. 背诵操作（极简2种模式）
   - 浏览跟读：看诗默读、熟读
   - 遮挡自测：隐藏诗句，自己背诵后再看原文核对
4. 背诵完成后标记3种状态：**熟练 / 一般 / 不熟练**
   - 熟练：按标准记忆曲线走间隔
   - 一般/不熟练：自动缩短复习间隔，优先安排高频复习
5. 系统自动从全题库中**筛选到期、不熟练的诗词**进入复习列表，无需手动安排

### 模块4：复习提醒（iOS核心能力）
1. 支持**iOS系统本地推送通知**
2. 可自定义设置：每日提醒时间
3. 到点推送提醒：「今日有多首古诗词需要背诵复习」
4. 未完成复习任务，次日自动保留待复习列表，不遗漏
5. 支持开关：开启/关闭每日复习提醒

### 模块5：个人设置（极简家长设置）
1. 每日学习限额设置：每天最多新学几首（1-3首可选）
2. 提醒时间自定义、开关提醒
3. 重置单首诗词记忆进度（背不好可重新从头记）
4. 清空学习进度（换孩子使用可重置）

## 五、MVP业务完整闭环
家长/小朋友打开App → 浏览选诗开始新学 → 标记掌握程度 → 系统按记忆曲线**自动筛选待复习诗词** → 到时间iOS推送提醒 → 进入App完成复习 → 自动更新记忆周期，循环闭环。
